# Change Control

- Make changes traceable to a task, requirement, or explicit maintenance need.
- Keep each change focused and preserve unrelated user work.
- Update directly related documentation when behavior, interfaces, or framework policy changes.
- Validate the changed behavior with the narrowest suitable checks, then broaden checks when risk warrants it.
- Identify intentional behavior changes and their impact.
- Summarize changed areas, validation performed, and any known limitations at handoff.
