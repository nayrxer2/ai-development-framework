# Terminology

| Term | Meaning |
|---|---|
| Agent | A role-defined AI worker with a bounded responsibility and expected outputs. |
| Orchestrator | An agent responsible for understanding work, coordinating contributors, and integrating outcomes. |
| Skill | Reusable domain knowledge or a procedure that can be loaded when relevant. |
| Rule | A constraint or expectation that governs work across one or more agents. |
| Workflow | An ordered process for completing a class of work. |
| Handoff | A structured transfer of work, context, and responsibility between agents or people. |
| Adapter | A mapping between framework concepts and a specific platform or toolchain. |
| Project context | The requirements, constraints, architecture, and conventions specific to a project. |
| Evaluation | A repeatable check of an agent, skill, workflow, or framework behavior. |
| Decision record | A durable record of a significant choice, its context, and consequences. |
